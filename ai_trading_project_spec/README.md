# AI Trading System — Copilot Starter Pack

This folder contains project planning documents, not a functioning trading bot.

1. Create an empty local Git repository in VS Code.
2. Copy all `.md` files into the repository root.
3. Open GitHub Copilot Chat in Agent mode.
4. Paste the contents of `FIRST_COPILOT_PROMPT.md`.
5. Review the proposed plan before allowing changes.
6. Start with synthetic test data and simulation only.

Broker: Pepperstone EU, cTrader Open API (application approval pending).
Markets: WTI, gold, EUR/USD, S&P 500; timeframes 1m and 5m.

Do not store broker credentials in these files or in Git.
